# LitForge 三服务真实 GPU 验收（2026-10-28）

本轮经用户明确授权，使用指定的已有单人验收视频、官方人物参考图及17帧控制视频，上传到现有上海火山 TOS `clipforge` 私有桶；复用既有 Temporal `ai-media` Caller 和三条 Worker 队列。每项只提交一个新 Workflow，串行执行，没有重提或重启 Worker。三项均完成 GPU 服务执行、PUT 回传、调用方下载、字节/SHA256校验、稳定本地归档及 HTTP 恢复查询。

## 验证证据

- opt-in 真实验收用例：1项通过，约791.6秒；其中模型阶段耗时不是服务性能承诺。人物替换 attempt_wall 约356.8秒（生成295.6秒），VACE 约353.0秒（生成346.0秒）。
- 三个文件均以 FFmpeg 完整解码到 null，退出码0、无错误；FFprobe逐帧计数分别为77、17、77。
- 三个 `/api/ai/video/task` 原任务恢复请求均返回 HTTP 200 / completed，返回 SHA 与归档一致；请求不提供浏览器 API Key 或 Endpoint。
- Chrome 对三项视频均 readyState=4、ended=true、error=null；解码尺寸和时长与 FFprobe 一致。
- 本地回归1928项通过、2项默认跳过；真实 GPU 用例在普通回归与CI中仍默认跳过，避免自动消耗资源。类型检查、生产构建通过；ESLint零错误、12项原有警告。
- 实际恢复查询发现并修正了可选 Endpoint 缺失时日志包装报错的问题，新增真实路由＋Provider工厂的 keyless/无Endpoint回归。音轨元数据按请求的 copy-source 模式返回，Wan 原始时长按已验证的帧数/FPS返回，不将模型名称或请求整数时长当作实际媒体属性。

本机脱敏报告、工作流回执、浏览器参数/截图和抽帧图保存在忽略目录 `data/verification/litforge-20261028/`。私密配置、签名 URL、输入素材和视频产物不提交 GitHub。

## 质量与覆盖范围

抽帧可见人物动作变化，文件无解码错误；这是小样例的服务集成与媒体交付验收。样例使用已有生成结果和同一官方人物参考，不能据此评价不同人物身份替换准确率。VACE 的背景和文字可发生变化，Canny不保证原场景逐像素保留；不把 API 成功当作严格画质达标。

本轮没有验收720P/长视频、所有人物/服装/遮挡组合、并发性能或完整 Agent 规划＋语音制作链。GPU/TOS单价和实际账单未核实，费用仍保持未知。主机证书、权限和Worker配置未变。
