# 复刻任务计费与发布导出

2026-10-28，本地实现与验证。

## 使用方式

- 设置中的视频模型选择、视频复刻分段参数和 Agent 视频配置显示百炼 Wan 3.0 / Prime 价格。分段价格跟随所选分辨率；通用目录显示中国区 480P 起价及全部档位说明。
- 我的项目和作品卡片显示项目累计费用，人民币与美元分别合计，未定价调用单独提示。总额来自调用记录与独立的最小费用台账，按调用 ID 去重；清空/淘汰调用日志不会清除已累计的任务费用。新任务重试属于新的调用，计入累计。
- 主播库删除须确认，取消不改变数据；原始照片、定妆图和编辑中的照片均可点击放大。
- 视频复刻合成成功后进入作品列表。历史草稿中的成片会按素材 ID 幂等补登记，不重新生成视频；后续每次合成保留独立成片。
- 已完成 Agent 和视频复刻的详情，以及作品卡片提供“发布”。弹窗复用既有多平台导出面板，可预览构图、选择平台并下载适配成片；平台选择与构图方式在同一浏览器内保存复用。支持现有七个平台，不会自动上传到社交平台。
- 导出锁定所选完成版本及项目归属；未完成、跨项目或已丢失的版本不可替代为另一个成片。Agent 超分作品也可从作品卡片导出。

## 计费依据与边界

[百炼官方价格](https://help.aliyun.com/zh/model-studio/model-pricing)于 2026-10-28 核对：中国区 Wan 3.0 的 480P / 720P / 1080P 原价分别为 ¥0.3 / ¥0.6 / ¥1.2 每秒，Prime 分别为 ¥0.45 / ¥0.9 / ¥1.8 每秒。新加坡国际端点使用该页的对应区域价格。

输入视频与输出视频均计费。[Wan 3 API usage](https://help.aliyun.com/en/model-studio/wan3-video-generation-api-reference) 的 `duration` 已是两者合计，不能再次相加。异步查询跨请求/重启仍修订原调用；回执存在时按返回的计费秒数、输出分辨率更新。无回执时使用已知时长和档位估算，不把未知费用当免费。

页面金额为调用用量和公开单价推算，不是账户账单实付，不包含免费额度、促销或合同折扣。未知定价的超分等调用保留“费用待确认”。历史记录仅在保留了足够用量信息时补估价；上线前已删除的调用记录无法还原。

## 2026-10-28 发布默认超分与清晰度对比

- 所有“发布”入口在打开时读取当前成片对应的原片/超分版本，默认选择同一成片最新完成并已归档的超分版；没有可用超分版时使用原片。不会跨项目或跨生成版本取片，也不会自动提交超分。
- 发布下拉选项、预览标题、当前导出提示和作品卡片显示原片/超分类型与实际 `宽 × 高`。原片用本地 ffprobe 元数据，超分用已校验的产物元数据；无法读取时显示未知，不把目标设置当实际分辨率。
- “切换预览原片”查看超分前成片，“返回预览导出视频”返回所选版本。切换保留播放位置，仅影响播放器；构图预览与多平台导出始终锁定下拉选定的版本，页面分别标注“正在预览”和“当前导出”。手动选择原片导出会清除旧的导出结果。
- 新增 `GET /api/project/:id/publish-videos?sourceId=...` 返回同一成片的已完成版本与默认 ID。扩展导出对视频复刻超分产物的解析，修正 Agent 已校验缓存位于 uploads/output 之外时不能导出的问题。浏览器只收到资源 ID、URL、尺寸等展示字段，不返回存储凭据。
- 本轮全量回归：204 文件通过，1902 项通过、1 项跳过；随后补充的加载失败/重试测试通过，发布版本与交互共 5 项测试通过。TypeScript、相关文件 ESLint 与生产构建通过。
- 实际浏览器：从 480×854 复刻原片卡片打开发布，默认 `remake-upscale-45764542-289f-45ce-bbc0-7d06dac9d418`，1080×1920；切换原片后播放器实测 480×854、导出仍锁定超分版。成功导出小红书1080×1440、9.033333秒，保留音轨，全量解码通过。
- 实际 Agent：从 496×864 原片进入发布，默认该版本最新完成的超分 `agent-upscale-10200fb2-c21c-4199-926c-f99d70882ef7`，实际播放器1080×1920、构图预览成功；可切换原片对比。控制台无错误。本轮无新增模型生成或超分提交。
