## 验收中修复的问题

超分面板的下载链接此前只附加 `?download=1`。Agent 资源路由会处理该参数，但视频复刻归档后的 `/api/files` 路由不会据此强制下载，因此实际点击会导航到视频。现共享链接增加 HTML `download` 属性，Agent 和视频复刻两处 UI 回归都验证下载语义。修复前两项回归在下载断言处失败，修复后通过；真实浏览器重放确认不再离开成片页。

另补充既有测试表中的音轨丢失、时长改变以及错误 request ID / 媒体类型 / 上传模式场景，确认无效结果不会发布为已完成的可播放素材。
